# 记账程序(复式记账 · 面向会计与审计)

一个 **Windows 桌面版复式记账程序**,采用借贷记账法,数据存储在本地单文件 SQLite 数据库(`.db`),内建审计追踪、自动备份与一键回滚。面向没有编程经验的会计与审计人员。

## 技术栈

- **Electron** 桌面框架 + 原生 HTML/CSS/JS 界面(无构建步骤,开箱即用)
- **sql.js**(SQLite 编译为 WASM)—— 零原生编译依赖,数据是标准 `.db` 文件,可用任意 SQLite 工具打开审计
- **BigInt 整数运算** —— 金额以「分」为单位存储、BigInt 精确运算,杜绝浮点误差

## 已实现功能

- **双会计准则科目表**:企业会计准则 / 小企业会计准则,建账时选择
- **两种角色登录**:会计(可编辑)/ 审计(只读),角色约束贯穿所有写操作
- **凭证管理**:录入(借贷平衡强校验、外币+汇率换算)、审核/反审核、记账/反记账、作废、冲销(蓝字)
- **账簿与报表**:试算平衡表、明细账、总账、资产负债表、利润表、现金流量表
- **外币与汇率**:多币种、每月汇率,外币金额自动换算为本位币
- **审计追踪**:所有操作(创建/修改/审核/记账/结账/回滚等)只追加记录,含改前/改后值
- **备份与回滚**:手动备份、回滚到任意版本,回滚前自动再备份当前状态
- **期末处理**:结转损益(自动生成结转凭证)、结账/反结账,已结账期间禁止修改
- **打印与导出**:凭证/试算平衡/报表 A4 打印,试算平衡/明细账/总账导出 CSV(Excel 可打开)

## 快速开始

```bash
npm install        # 安装依赖
npm start          # 启动应用(Windows 桌面窗口)
npm run smoke      # 运行核心逻辑冒烟测试(无需界面)
npm run dist       # 打包 Windows 安装包(产物在 dist/)
```

首次启动会进入「登录 → 建账向导」流程。

## 数据与备份

- 运行数据在 `data/ledger.db`(开发模式);打包后位于系统用户数据目录
- 快照备份在 `data/snapshots/`,回滚记录在 `data/restore.log`
- 备份 = 复制 `.db` 文件,可随时手动复制到安全位置
