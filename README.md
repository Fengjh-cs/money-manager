# 记账程序

> 面向会计与审计的 Windows 桌面版复式记账软件 · 借贷记账法 · 本地单机 · 数据加密 · 全程审计可追溯

一个**开箱即用**的复式记账程序。采用标准的借贷记账法,覆盖从建账、凭证、账簿、报表到期末结账的完整会计流程,并针对审计场景内建了操作日志、自动备份与一键回滚。目标用户是**没有编程经验的会计和审计人员**——中文界面、向导式引导、双击即用。

---

## 核心特性

### 记账核心
- **双会计准则科目表**:企业会计准则 / 小企业会计准则,建账时二选一;预置常用一二级明细科目(费用、税费、职工薪酬、权益、成本类),也可自行新增
- **凭证全流程**:录入(借贷平衡强校验、外币+汇率换算)→ 审核 / 反审核 → 记账 / 反记账 → 作废 / 冲销(蓝字更正)
- **账簿与报表**:试算平衡表、明细账、总账、资产负债表、利润表、现金流量表(直接法 + 间接法)
- **期末处理**:期末调汇、结转损益(自动生成结转凭证)、结账 / 反结账,已结账期间禁止修改

### 审计与安全
- **双角色登录**:会计(可编辑)/ 审计(只读),各自独立密码,角色约束贯穿所有写操作(界面隐藏 + 服务端拦截双层防护)
- **审计追踪**:所有操作(创建/修改/审核/记账/结账/回滚/登录等)只追加记录,含改前/改后值,不可篡改
- **数据加密**:数据库文件采用 AES-256-GCM 加密,启动需输入「数据库密码」解锁
- **备份与回滚**:手动备份、回滚到任意版本(回滚前自动再备份当前状态);结账前、每日自动备份

### 效率与专业
- **多币种与汇率**:多币种、每月汇率,外币金额自动换算为本位币
- **辅助核算**:往来单位 / 部门 / 项目,分录关联、按对象查明细
- **多账套**:创建 / 切换多个账套,数据互相独立
- **批量导入**:期初余额、凭证均支持 CSV 批量导入(可下载模板)
- **打印与导出**:凭证 / 试算平衡 / 报表 A4 打印,凭证套打(针式凭证纸,含偏移微调),试算平衡 / 明细账 / 总账导出 CSV(Excel 可打开)

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面框架 | **Electron** | 跨平台桌面,界面用原生 HTML/CSS/JS,无构建步骤 |
| 数据库 | **sql.js**(SQLite→WASM) | 零原生编译依赖;数据是标准 `.db` 文件,可用任意 SQLite 工具打开审计 |
| 金额运算 | **BigInt 整数** | 金额以「分」为单位存储、BigInt 精确运算,杜绝浮点误差 |
| 加密 | **AES-256-GCM + scrypt** | 数据库文件加密,密钥由主密码派生 |
| 打包 | **electron-builder** | 生成 NSIS 安装包 `setup.exe` |

**为什么这样选**:单机本地、零配置、数据完全自持;金额精确性(金融红线);`.db` 文件对审计方透明可查。

## 快速开始

### 方式一:直接安装(推荐)

下载 `dist/记账程序 Setup 0.1.0.exe`,双击安装即可(未签名,SmartScreen 提示时点「更多信息 → 仍要运行」)。

### 方式二:从源码运行

```bash
npm install        # 安装依赖
npm start          # 启动应用(Windows 桌面窗口)
npm run smoke      # 运行核心逻辑冒烟测试(70 项,无需界面)
npm run dist       # 打包 Windows 安装包(产物在 dist/)
npm run icon       # 重新生成应用图标
```

首次启动会进入「登录 → 建账向导」流程。

## 使用指南

### 1. 建账(首次使用)
1. 启动 → 选「会计」登录,默认密码 `123456`;
2. 建账向导:填公司名称 → 选会计准则 → 选启用期间 → **设置数据库密码**(请牢记,遗忘无法找回);
3. 录入期初余额(可单科目录入,或下载模板批量导入)。

### 2. 日常记账
录入凭证(借贷不平衡会被拦截)→ 审核 → 记账 → 随时查看试算平衡 / 明细账 / 总账 / 报表。

### 3. 期末处理(每月)
「期末处理」页依次:**期末调汇**(外币账套,可选)→ **结转损益** → 到「凭证管理」审核并记账结转凭证 → **结账**锁定该期间。

### 4. 审计
- 用「审计」身份登录(默认密码 `123456`),只能查看、不能修改;
- 「审计日志」可查看全部操作轨迹;
- 「备份与回滚」可查看历史版本并回滚。

### 5. 备份与回滚
- 手动「立即备份」,或依赖结账前 / 每日自动备份;
- 需要时在备份列表点「恢复到此版本」即可回滚。

## 数据与安全

- 运行数据在 `data/ledger.db`(开发模式);打包后位于系统用户数据目录;
- 数据库文件 **AES-256-GCM 加密**,启动需「数据库密码」解锁;
- 快照备份在 `data/snapshots/`(同样加密),回滚记录在 `data/restore.log`;
- 备份 = 复制 `.db` 文件,可随时手动复制到安全位置。

## 已知限制

- 现金流量表(直接 + 间接)和期末调汇为**简化版**(分类/调整规则见 `src/services/ledger-service.js` 源码注释);
- 期末调汇的外币余额取自已记账分录,**不含期初外币余额**(期初余额目前只存本币金额);
- 凭证套打按通用凭证纸尺寸(210×140mm)预设坐标,需根据实际凭证纸微调「套打设置」偏移值;
- 安装包未做代码签名(SmartScreen 会提示「未知发布者」)。
